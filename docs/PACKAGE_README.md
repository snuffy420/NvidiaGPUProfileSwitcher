# NVIDIA GPU Driver Profile Switcher 2.0

Windows 10 version 2004+ / Windows 11, x64.

## Start

Open the included NVIDIA-GPU-Driver-Profile-Switcher-v2.0-Portable-Windows-x64.exe.
Python, Qt, the app icon, and the extraction tool are bundled. No dependency
downloads or separate Python installation are needed.

Keep the portable EXE, assets, and licenses inside this containing folder.
Profiles and settings are created beside the EXE; caches, downloads, history,
and recovery folders are created as features are used. Keep the folder writable.

Click a profile card to select it. Use Restart as administrator before changing
GPU or driver state. Selecting, saving, or caching a profile does not install
drivers. Actual switching requires a separate confirmation and can require a
Windows restart. No NVIDIA drivers or someone else's profiles are included.

## Existing users

Back up your profile/settings files and keep your driver caches when replacing
the application. Do not overwrite your own data files with files from another
machine. If moving the app, select your existing cache folder and verify your
profiles afterward. Installer upgrades preserve generated data; uninstall also
retains profiles, caches, downloads, history, and recovery files.
