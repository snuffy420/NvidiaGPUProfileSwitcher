# NVIDIA GPU Driver Profile Switcher v2.0

Version 2.0 replaces the original Tkinter interface with a Qt desktop interface
and adds cache-location and cache-management tools for mixed-generation NVIDIA
systems.

## Changes

- Qt interface with dark/light themes, clickable profile cards, green navigation,
  a custom window header, and resizable device/detail panels.
- Select a writable cache folder and detect existing app-cached packages without
  moving or deleting them.
- Review cache versions, locations, saved-profile usage, and recovery references.
  Packages used by saved profiles are protected from deletion.
- Build profiles directly from cached packages with their actual expected version.
- Retain per-GPU driver targets, disabled states, and leave-unchanged roles.
- Preserve EXE import, installed-driver capture, NVIDIA update checks, Windows
  compatibility checks, recovery history, and Device Manager code reference.
- Application icon bundled and assigned to both the Qt window and Windows EXE.
- Original GPU/profile-switching application icon, separate from the in-app
  vendor logo.
- Isolated release build environment prevents unrelated tools' runtime DLLs
  from entering the application and breaking Qt startup.
- Custom dark Inno Setup installer with project artwork and icon, per-user
  installation, Start menu entry, optional desktop shortcut, and uninstall entry.
- Updated documentation and v2.0 screenshots, plus a project-themed contact form.

## Choose a download

- **Setup-Windows-x64.exe**: install the self-contained application for your Windows account.
- **Portable-Windows-x64.7z**: extract its containing folder and run the EXE inside it.
- **Source.7z**: Python source, requirements, build scripts, documentation, and screenshots.
- Matching **.sha256** files verify each download.

The installer and portable version require no separate Python installation or
dependency downloads. NVIDIA drivers and preconfigured profiles are not included.

## Existing users

Back up your application data and keep your cached packages when upgrading.
Profiles and settings are saved beside the app; caches can use a separate
configured folder. If installing in a different folder, copy the intended
profile/settings files and select your existing cache folder. GPU IDs remain
machine-specific. Verify your profiles and test your AI workload after upgrading.

Driver switches still perform real Windows driver installations and may need a
restart. Installing the application itself does not change GPU/driver state.
