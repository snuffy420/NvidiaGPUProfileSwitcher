# NVIDIA GPU Driver Profile Switcher v2.2.0

- Remove the redundant administrator-status line from the main window.
- Cache/import NVIDIA driver packages independently from saved profiles.
- Simplify profile creation to one cached driver choice and automatic INF
  selection based on the GPUs selected for the profile.
- Search a broader NVIDIA catalogue range for the newest package confirmed for
  all present GPUs and label per-GPU upgrades/downgrades.
- Allow more time for NVIDIA's driver catalogue to respond.
